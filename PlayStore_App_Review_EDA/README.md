# Google Play Store App Review Analysis (EDA)

This project explores Google Play Store app data to understand how **ratings, reviews, installs, and categories** influence app performance.

## 🎯 Objective
To analyze Play Store apps and find what factors are linked with **higher ratings, more installs, and better user engagement**.

## 📂 Dataset
- App-level data: category, rating, reviews, installs, price, size, type (free/paid), etc.
- User review information for sentiment and feedback patterns.

## 🛠️ Tools & Technologies
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- Jupyter/Colab Notebook

## 🔍 Key Steps
- Data cleaning: removing duplicates, fixing data types, handling missing values
- Univariate & bivariate analysis of ratings, installs, and price
- Category-wise comparison and visualization
- Basic sentiment overview from user reviews (positive/negative trends)

## 📊 Key Insights
- Identified **top-performing app categories** by rating and installs
- Found patterns in **free vs paid apps**
- Highlighted how **reviews and installs** relate to app rating
