# Yes Bank Stock Closing Price Prediction (Regression)

This project builds a **regression model** to predict the **closing price** of Yes Bank stock using historical market data.

## 🎯 Objective
To understand how market features (open, high, low, volume, etc.) affect the closing price and to build a model that can predict future closing prices.

## 📂 Dataset
- Historical daily stock data for Yes Bank
- Columns include: Date, Open, High, Low, Close, Volume, etc.

## 🛠️ Tools & Technologies
- Python (Pandas, NumPy, Scikit-learn, Matplotlib)
- Jupyter/Colab Notebook

## 🔍 Key Steps
- Data cleaning and handling missing values
- Exploratory data analysis and correlation study
- Feature scaling (if used) and train–test split
- Regression modelling (e.g., Linear Regression / other models)
- Model evaluation using MSE, RMSE, and R²

## 📊 Key Insights
- Understood which variables have strong correlation with closing price
- Built a baseline regression model for stock price prediction
- Interpreted model performance using standard regression metrics

## 📁 Files
- `YesBank_Stock_Prediction.ipynb` – model building and evaluation
