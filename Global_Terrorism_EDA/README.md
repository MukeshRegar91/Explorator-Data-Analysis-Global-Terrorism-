# Global Terrorism Exploratory Data Analysis (EDA)

This project analyzes the Global Terrorism dataset to understand how terrorist incidents vary across **countries, time, attack types, and targets**.

## 🎯 Objective
To identify key patterns and trends in global terrorism incidents that can help researchers, policymakers, and security teams understand high-risk regions and attack behaviours.

## 📂 Dataset
- Source: Global Terrorism Database (GTD)
- Contains information about **year, country, city, attack type, target, weapons, casualties**, etc.

## 🛠️ Tools & Technologies
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- Jupyter/Colab Notebook

## 🔍 Key Steps
- Data cleaning: handling missing values, filtering irrelevant columns
- Feature engineering: creating year-wise and region-wise summaries
- Exploratory analysis using groupby and pivot tables
- Visualizations for trends over time and by region

## 📊 Key Insights
- Identified **most affected countries and regions** over the years
- Observed **rising and falling trends** of attacks over time
- Highlighted **most common attack types and targets**
